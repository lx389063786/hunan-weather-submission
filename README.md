# 投稿助手 · 湖南气象市县动态写稿机器人

模仿湖南省气象局「市县动态」栏目文风，为新邵县气象局自动撰写新闻稿件，支持人工审核、微信推送与投稿平台提交。

## 快速开始

```bash
npm install
node server.js
```

打开 http://localhost:3000 使用网页界面。

## 配置

1. 首次运行后，复制 `config.json` 的配置结构（填入你的 PushPlus token）。
2. 微信扫码登录 pushplus.plus → 关注公众号 → 复制 token；**必须完成实名认证（免费）** 才能发送。
3. 在网页「设置」中填入 token、可选的审核页面外网地址与投稿平台接口。

## 功能

- 按素材写稿（500—900 字，内置文风规范与天气事实核查）
- 每日自动写稿 + 微信推送（可配定时任务执行 `node src/daily.js`）
- 草稿审核：编辑 / 复制 / 重新生成 / 驳回 / 推送 / 投稿
- 统一署名与推送去重

完整说明见 `Agent.md`。

## 安全提示

`config.json` 含个人凭证，已在 `.gitignore` 中排除，请勿提交真实 token。
